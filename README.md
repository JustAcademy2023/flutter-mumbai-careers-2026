# flutter-mumbai-careers-2026

A vibrant, single-page landing site answering **"Is Flutter Worth Learning in 2026? Career Opportunities in Mumbai"** — built with a playful Flutter-blue palette, an animated "local train route" career map, and fully responsive cards for the course and blog reads.

## ✨ Highlights

- **Signature visual** — an animated SVG "local train" route map turning the learning journey (Dart → Widgets → Projects → Portfolio → Mumbai Job) into a fun station-by-station story.
- **Distinct palette** — deep ink navy, Flutter sky-blue, Mumbai-sunset coral and gold, paired with Space Grotesk + Inter + JetBrains Mono typography.
- **Fully responsive** — fluid grid layouts, mobile-friendly nav, and touch-safe tap targets down to small phone widths.
- **Fully clickable cards** — course and blog cards are wrapped as single links, no hunting for tiny "read more" text.
- **Zero dependencies** — plain HTML/CSS/JS, so it works out of the box on GitHub Pages.

## 🚀 Run it locally

```bash
git clone https://github.com/<your-username>/flutter-mumbai-careers-2026.git
cd flutter-mumbai-careers-2026
open index.html   # or just double-click it
```

## 🌐 Deploy on GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under "Build and deployment", set **Source** to `main` branch, `/ (root)`.
4. Save — your page will be live at `https://<your-username>.github.io/flutter-mumbai-careers-2026/`.

## 🛠️ Tech Stack

- HTML5, CSS3 (custom properties, grid/flexbox, keyframe animations)
- Inline SVG for the route-map illustration
- Google Fonts: Space Grotesk, Inter, JetBrains Mono
